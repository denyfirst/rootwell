      How do I add these DNS records?

      Choose type TXT in your DNS provider. Use each Name and Value exactly as shown. Some providers append your domain automatically: enter only the relative name there, such as _acme-challenge. Do not put the name in twice.

      If two records have the same Name, keep both Values; do not overwrite the first one. Do not replace unrelated TXT records. Rootwell does not edit or look up your DNS in this step.

      Your acknowledgement does not verify DNS. Staging is test-only, not for production. Make a new complete backup after saved changes.

      What happens to my request and key?

      “Ask CA to check DNS” requests validation; “Refresh CA result” only reads the same request. After confirmed verification, “Prepare certificate key” saves one encrypted key and signed request locally. Then “Get test certificate” sends only that signed request, checks the returned certificate and saves it with the same key in Certificates. The private key never goes to the CA. An uncertain result allows only “Check certificate result” — no resend or automatic polling.

      Renew a saved test certificate

      In Certificates, choose “Renew test certificate”. Its saved domains are selected for you. First close the old completed or known-expired request if needed, then confirm a separate renewal with your password. The original certificate, key and notes stay saved; a new key is prepared later and both checked certificates remain separate. Unknown or active requests cannot be replaced. Local closure is not CA cancellation or revocation. DNS automation, production issuance and server deployment remain separate next steps.
