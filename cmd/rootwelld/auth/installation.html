Backup

A backup holds every certificate, key, account and passkey, sealed. It opens only with the instance key, which it never holds: keep the key's recovery code apart from your backups.

On the server

These run at the server's terminal, with Rootwell stopped:

  • rootwelld restore puts a backup back into an empty data directory. A backup opens only with the key the vault had when it was made.
  • rootwelld key-rotate moves Rootwell to a new instance key and shows its new recovery code. Backups made before keep opening with the old key only.
  • rootwelld key-export shows the recovery code of the key in use.
