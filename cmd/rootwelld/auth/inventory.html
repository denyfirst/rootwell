PUBLIC CERTIFICATE INVENTORY

Know what is saved.
Know what is not proven.

Save public certificates with an owner and list where you believe each is used. These are manual notes, not proof of trust, deployment, revocation, or private-key possession.

Different from offline Workbench

Pressing Save sends the selected public certificate file to your own loopback Rootwell server. It is stored encrypted in this installation. Never select a PFX or private-key file. Rootwell does not contact a third-party service.

01 / EXPLICIT SAVE

Add public certificates

One DER certificate or one PEM certificate/bundle, up to 16 MiB. A bundle is saved all-or-nothing. Repeated certificates are refused; add another location to an existing card instead.

02 / STORED RECORDS

Expiry overview

Expiry uses this browser’s clock; save time uses the server’s clock. Neither is a tamper-proof audit log or a trust verdict.

    Backup is manual

    After saving certificates or locations, stop Rootwell and run rootwelld inventory-snapshot with a new backup filename. Verify and store the snapshot separately from your recovery code. An old snapshot cannot restore later changes.
