PUBLIC CERTIFICATE INVENTORY

Know what is saved.
Know what is not proven.

Save public certificates with an owner and location so you can find them before expiry. Nothing here proves trust, deployment, revocation, or private-key possession.

Different from offline Workbench

Pressing Save sends the selected public certificate file to your own loopback Rootwell server. It is stored encrypted in this installation. Never select a PFX or private-key file. Rootwell does not contact a third-party service.

01 / EXPLICIT SAVE

Add public certificates

One DER certificate or one PEM certificate/bundle, up to 16 MiB. A bundle is saved all-or-nothing. Repeated certificates are refused.

02 / STORED RECORDS

Expiry overview

Expiry uses this browser’s clock; save time uses the server’s clock. Neither is a tamper-proof audit log or a trust verdict.
